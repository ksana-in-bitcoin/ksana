Ksana wallet demo

Path B with Unisat or Xverse: the wallet signs the VmOp's sighash with BIP322, the fee is paid in KSA, and the producer sponsors the BTC fee, includes the operation in a fast-lane block and puts it on chain with the settlement transaction.

Mock wallet: the private key comes from the page URL; for local regtest testing only.

1. Node

The node must be started with --rpc-cors for the page to call it from the browser (D-055).
